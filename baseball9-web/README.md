# ⚾ 야구9단 매니저 (휴대폰·PC 브라우저용)

서버 없이 HTML 한 파일로 돌아가는 버전입니다. 게임 엔진은 JavaFX 버전 → Python(Flask) 버전을 그대로 JavaScript로 옮겼습니다.

- 선수 데이터: 2026 시즌까지 반영(KBO·NPB·MLB 공식 사이트 기록, 소속은 2026 시즌 마지막 팀 기준). 갱신은 `tools/fetch_kbo.py`·`fetch_npb.py`·`fetch_mlb.py` 로 받고 `tools/build_players.py` 로 재생성. 2026 시즌 후 FA 이적은 미반영
- 외국인 선수(NPB·MLB) 이름은 한국어: KBO 한글 이름 > 위키데이터 한국어 표기 > 위키데이터에서 배운 이름 사전 > 규칙 음역(일본어는 국립국어원 표기법, 영어·스페인어는 근사). 규칙 음역은 틀릴 수 있음. 영어 이름으로도 검색됨. 도구: `tools/korean_names.py`
- 게시된 링크: https://claude.ai/artifact/629y7xFCNY4Bh5MDLvjSSx
- `dist/play.html` 파일을 브라우저로 열어도 됩니다.

## 게임 구성 (야구9단 방식)

- **팀 선택 (시작 화면)**: 리그(KBO·NPB·MLB·월드)와 선수 기준(현역/역대)을 고르면 팀 카드가 나옵니다. 팀마다 실제 선수 로스터·전력·스타 선수가 다르고, 맨 위 팀부터 강한 순서로 보여줍니다. 팀을 고르면 그 팀 감독으로 시즌 시작. 운영 탭에서 다른 팀으로 새로 시작할 수 있습니다.

- **홈**: 오늘 경기, 오늘/7일 자동 진행, 다른 구장 결과, 상위 순위, 팀 다시 고르기(18/36/72/144경기)
- **화면 스타일**: 옛 네이버 야구9단처럼 네이비 바탕 + 오렌지 포인트, 리그 선택 타일, 흰 카드 팀 순위표(굵은 이탤릭 순위·팀 배지·게임차)
- **기사**: 경기가 끝날 때마다 우리 팀 경기 기사(헤드라인·수훈 선수·선발 투수·순위·연승/연패)와 리그 소식(큰 점수차 경기·선두 교체·홈런 선두·트레이드·올스타·우승)이 생성됨. 📰 기사 탭, 홈에 최신 기사 3건
- **PC에서 열기**: `dist/play.html` 파일을 크롬 등 브라우저로 더블클릭 (인터넷 없이도 동작, 저장은 그 브라우저에)
- **순위 탭**: 팀 순위 / 경기 일정(10경기씩 페이지, 결과·상대·팀전력·홈/원정). **라인업 관리**: 1군 타순·벤치·투수진 표(상태·타율·홈런·타점·도루), 선수를 눌러 선택 → 다른 선수를 눌러 교체, 우측 선수 상세, 선발 투수 지정. **결과 요약**: 득점·안타·홈런·도루·볼넷·삼진 막대 비교
- **올스타전·국가대표전도 일반 경기처럼**: 지휘하기를 누르면 라인업 관리 화면(타순 교체·선발 투수 지정)을 거쳐 시작. 올스타·대표 명단은 능력치 + 올 시즌 성적으로 선발
- **수비 위치(내가 설정)**: 라인업 관리 표의 '수비 위치' 칸에서 포수·1·2·3루·유격수·좌·중·우익수·지명타자를 직접 고름. 이미 그 자리에 있는 선수와는 서로 바뀜. 안 건드리면 자동 배정(발 빠른 외야수=중견수). 벤치 선수로 교체하면 그 자리를 이어받고, 경기 중 대타도 빈 자리에 자동 배정. 중계 화면·주루보기에 반영
- **방출**: 라인업 관리 화면에서 선수를 선택 → 방출(한 번 더 눌러 확정), 훈련 탭에서도 가능. 야수 9명·투수 5명 아래로는 방출 불가
- **2군**: 1군은 최대 28명(야수 9·투수 5 이상), 나머지는 2군. 드래프트 신인·영입 선수는 2군에서 시작하고, 2군에서 성장해 같은 역할의 1군 최약체보다 OVR이 3 이상 높아지면 3일마다 자동 콜업(정원에 여유가 있으면 실력만 인정되면 승격). 라인업 관리 화면에 2군 표와 1군 콜업/2군 내리기 버튼. 경기에는 1군만 출전
- **은퇴(자동)**: 40세가 되면 바로 은퇴, 35~39세는 나이·능력치에 따라 확률 은퇴(비시즌). 라인업 관리 화면에서 수동 은퇴도 가능. 은퇴 기사, 운영 탭 '은퇴 선수' 명단. AI 구단은 모자란 자리를 새 선수로 채움
- **경기 화면**: 네이버 스포츠 중계 스타일. 상단 스코어바(팀 배지·점수·이닝·주자 다이아몬드·B/S/OUT·투수 투구 수), 3분할 구성(좌: 스코어보드·타순, 중: 중계 화면·기록, 우: 투수·타자 카드). 타석 시점(스트라이크 존에 투구별 번호·구종·구속 표시)과 주루보기(수비 위치별 선수 이름·주자·대기타석) 전환, 득점/이닝별 중계 탭
- **경기**: 타순·선발 지정 후 투구 단위 중계로 직접 지휘 (번트·도루·대타·대주자·고의4구·투수교체·구종 사인)
- **순위 / 기록**: 10개 구단 순위표, 리그 리더(타율·홈런·타점·OPS·평균자책점·탈삼진·다승), 우리 팀 기록
- **훈련**: 경기마다 쌓이는 포인트로 능력치 +1(잠재력까지) 또는 휴식
- **영입**: KBO·NPB·MLB 역대 선수 31,600명 중 검색해서 훈련 포인트로 영입, 훈련 탭에서 방출
- 리그: KBO(10팀) / NPB(12팀) / MLB(30팀) / **통합 리그(KBO·NPB·MLB 52팀 전체가 한 리그)** / 월드 리그(세 리그 강팀 12팀). 선수 기준은 현역(마지막 시즌 소속) 또는 역대 레전드(가장 오래 뛴 구단, 전신 포함)
- 올스타전: 시즌 중반, 팬 투표(능력치 + 내가 진행한 올 시즌 성적 — 잘한 선수일수록 높은 점수)로 뽑은 두 그룹. 선발된 선수와 성적이 화면에 표시됨
- 국가대표 대회: 8개국 조별리그 → 4강 → 결승. 현역 대표는 능력치 + 올 시즌 성적(우리 리그 선수는 내가 진행한 경기 기록)으로 잘한 선수 순으로 선발, 역대 드림팀은 통산 능력치. 국적(KBO)·출생국(NPB·MLB) 기준, 리그를 오간 선수는 한 사람으로 묶음
- **육성**: 26세 이하는 비시즌에 성장, 32세부터 하락. 24세 이하는 시즌 중 출전하면 가끔 성장하고 훈련비도 쌈(2P)
- **세부 능력치**: 타자 컨택·파워·선구·주루, 투수 탈삼진·제구 (실제 기록에서 계산). 컨택→안타·삼진, 파워→홈런, 선구→볼넷, 주루→도루 성공률·진루, 탈삼진/제구→투수의 삼진·볼넷. 종합 능력치(OVR)에 이미 섞여 있으므로 본인 평균 대비 편차만 반영해 전체 득점 환경은 유지. 도루 기록·리더 포함
- **AI 트레이드 제안**: 4일마다 AI 구단이 우리 핵심 선수를 원하며 먼저 제안(수락/거절)
- **트레이드**: AI 구단과 선수 교환. 가치 = 능력치(비선형)·잠재력·나이. AI는 손해 보는 거래를 거절하고 이유를 말함
- **라커룸**: 선수 사기(실력 ±4)와 발언 — 활약 소감, 벤치 불만, 트레이드 요청, 피로 호소, 성장·노쇠, 이적 소감
- 선발 5인 로테이션, 투수 피로·회복, AI 구단 투수 운영
- 진행은 자동 저장 (claude.ai에서는 내 계정, 그 밖에서는 이 브라우저)

## 선수 데이터

`src/players.js` 는 `tools/build_players.py` 가 공개 기록에서 만듭니다 (KBO 3,420명 · NPB 7,304명 · MLB 20,876명).

- 출처: KBO 공식 기록(1982–2025), NPB 공식·npbstats, MLB [Lahman Database](https://sabr.org/lahman-database/) (CC BY-SA 3.0) — [frankmkpark/mnk_datasets](https://github.com/frankmkpark/mnk_datasets) 정리본
- 타자 능력치: 리그 평균 대비 OPS(OPS+) 전성기 3시즌 + 통산, 타석이 적으면 평균 쪽 보정
- 투수 능력치: 리그 평균 대비 평균자책점(ERA+) 전성기 3시즌 + 통산, 불펜은 할인, 선발은 이닝 보너스
- 리그 수준 보정: MLB 0, NPB −3, KBO −6 (리그끼리 맞붙을 때 차이가 나도록, 리그 안 순위는 그대로)
- 동일인 판정: 리그가 다른 기록(류현진 KBO ↔ Hyun Jin Ryu MLB)을 성 + 출생연도 + 이름 철자 유사도로 묶음 (1,393건)
- 국적: KBO 국적 우선, 그 외 출생국. 1945년 이전 한국·대만 출생 NPB 선수는 일본
- 한계: 수비는 데이터가 불충분해 반영하지 않습니다. 이치로처럼 컨택·주루형은 종합 능력치(OPS 기반)가 낮게 나오지만 세부 능력치로 보완됩니다

```bash
python3 tools/build_players.py --report   # 원본 CSV 를 받아(캐시) players.js 재생성 + 상위 선수 확인
```

## 개발

```bash
node build.js            # src/ → dist/play.html (+ 로컬 확인용 dist/preview.html)
node --test tests/engine.test.js
```

- `src/engine.js` — 모델, 중계 멘트, 경기 엔진(타자·투수 기록 포함)
- `src/season.js` — 시즌 모드: 구단 구성, 일정, 순위, 기록, 훈련, 저장/불러오기, API(dispatch)
- `src/players.js` — 선수 DB (Java PlayerDB 에서 변환)
- `src/play.src.html` — 화면 (휴대폰에서는 전광판 → 그라운드·중계 → 버튼 → 타순 순서)


- **드래프트(10라운드)**: 시즌이 끝나면 꼴찌 팀부터 10라운드. 풀은 KBO·NPB·MLB 역대 실존 선수를 무작위로 약 1,600명 — 같은 선수도 시즌마다 따로 나옴(“09 양현종”, “17 양현종”: 그 해 나이·능력치, 1982~)하고 기본 선수도 섞임. 리그 필터·이름/연도 검색, 남은 지명 자동, 지명 포기. 지명되면 다른 팀과 겹치지 않음. 로스터 최대 40명

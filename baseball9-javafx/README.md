# ⚾ 야구9단 매니저 (JavaFX)

실제 경기처럼 투구 단위로 진행되는 야구 시뮬레이션입니다. 감독으로서 작전을 내고, 중계 멘트를 들으며 경기를 운영합니다.

## Windows에서 실행 (가장 간단)

1. JDK 21 설치: https://adoptium.net 에서 Windows x64 `.msi` (Temurin 21) 설치
2. 배포 zip 압축 풀기
3. 압축 푼 `baseball9\bin\baseball9.bat` 를 더블클릭

## 실행 (개발용)

```bash
gradle run          # 앱 실행
gradle test         # 엔진 단위 테스트
```

JDK 21 + JavaFX 21 이 필요합니다 (build.gradle 에 설정되어 있음).

## 경기 화면 조작

| 구분 | 버튼 | 설명 |
|---|---|---|
| 진행 | ▶ 한 구 | 투구 1구 진행 |
| 진행 | ⏭ 한 타석 | 타석이 끝날 때까지 진행 |
| 진행 | ⏩ 이닝 | 이닝이 끝날 때까지 진행 (판단 지점에서 멈춤) |
| 진행 | ▶ 자동 중계 | 자동으로 투구 진행. 감독 판단 지점에서 자동 일시정지 |
| 진행 | 🏁 끝까지 | 경기 종료까지 한 번에 진행 |
| 공격 | 🥎 번트 | 다음 투구에 희생번트 시도 |
| 공격 | 🏃 도루 | 1루/2루 주자 도루 시도 |
| 공격 | 🔁 대타 | 벤치 선수로 현재 타자 교체 |
| 공격 | 🏃 대주자 | 주자를 벤치 선수로 교체 |
| 수비 | 🚫 고의4구 | 상대 타자 고의4구 (1루가 비어 있을 때) |
| 수비 | 🔄 투수 교체 | 불펜 투수 등판 |
| 수비 | 구종 사인 | 자동 / 직구 위주 / 변화구 위주 / 유인구 |

- 주자가 있는 상황에서 우리 공격이 시작되거나, 우리 투수의 체력이 45 미만으로 떨어지면 자동 중계가 멈춥니다.
- 중계 로그 색상: 안타(초록), 득점(빨강), 볼넷(파랑), 도루(노랑), 감독 지시(금색), 해설(보라)

## 구조

- `engine/GameEngine.java` — 투구 단위 시뮬레이션, 감독 지시 처리 (UI 독립)
- `engine/Commentary.java` — 한국어 중계 멘트 생성
- `engine/GameManager.java` — 팀/리그/선수 관리, 로스터 생성, 경기 후 피로도
- `model/` — `GameState`, `TeamState`, `PitcherLine`, `Player` 등
- `ui/GameScreen.java` — 경기 화면 (로그, 득점판, 감독 버튼)
- `ui/FieldView.java` — 야구장 다이어그램 (주자, B-S-O 표시등)
- `ui/MainController.java` — 메뉴, 로스터, FA, 드래프트, 순위표, 결과 화면
